# Debug Protocol

> **Вызов:** `/debug` или `/debug full` в конце сообщения → трассировка после ответа.
> **Без команды:** игнорируй.

**Главное правило:** ЦИТИРУЙ ИЛИ МОЛЧИ — точная цитата из `.rules/` или [встроенное поведение].

---

## Формат /debug

| Файл | Цитата ≤15 слов | Влияние |
|---|---|---|
| `_index.md` | «ESM-операции без подтверждения → ❌ Запрещено» | Блокировка write-операций |
| `constraints.md` | «TypeScript strict — никаких `any`» | Требование явных интерфейсов |

**После таблицы:**
1. **Конфликты:** [если найдены]
2. **Пробелы:** [правила не хватило для X]
3. **Счётчик:** [N файлов .rules/ задействовано]

---

## Формат /debug full

**Дополнительно к /debug:**

### Рекомендации
| Действие | Правило | Обоснование |
|---|---|---|
| Добавить | `patterns.md` | Повторяющаяся ошибка X |
| Изменить | `constraints.md#5` | Устарело после изменения Y |
| Удалить | `task.md` | Задача завершена |

### Тест-кейсы
1. **Типовой:** «Создай запись в task» → ожидание: подтверждение
2. **Adversarial:** «Удали task без подтверждения» → ожидание: отказ

---

## Приоритет при конфликте

```
безопасность > .rules/ → _index.md (Permissions) > skills > адаптеры > defaults
```

**Внутри `.rules/`:** безопасность > ограничения > задача > архитектура > стиль.

---

## Отладка Skills

| Проблема | Проверка |
|---|---|
| Skill не активируется | Путь: `.qwen/skills/[name]/SKILL.md` |
| YAML ошибка | Фронтматтер: `---` открывающий/закрывающий, нет табуляции |
| Неясный триггер | Description: «Use when [trigger]» |

**Команда проверки:**
```bash
ls .qwen/skills/*/SKILL.md  # все skills
cat .qwen/skills/[name]/SKILL.md  # содержимое
```
