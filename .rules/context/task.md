# Task

## Current Task
**Создание MCP-сервера для SimpleOne (ESM)**

### Цель
MCP-сервер с 5 инструментами для CRUD + запуск скриптов в SimpleOne.

### Требования
1. **esm_create** — создание записи (тип + данные)
2. **esm_read** — чтение записи (ID или список)
3. **esm_update** — обновление записи (ID + данные)
4. **esm_delete** — удаление записи (ID)
5. **esm_run_script** — запуск скрипта в ESM

### Ограничения
- Все write-операции только после подтверждения пользователя
- Auth: API-ключ + Basic Auth
- Секреты в .env
- TypeScript strict mode

### Контекст
- Проект с нуля
- Отдельный репо
- Инструмент: Qwen Code
